Do / Don’t

Do

  • Use the outlined SVG wordmark (diamond locked to the title)
  • Keep the diamond square and ember (#E8761A)
  • Pair Spectrum Wing with the Diamond Period wordmark
  • Use white lockups on nav / dark chrome
  • Use SessionWip left of a session title while agent / model / Tessaron work is running

Don’t

  • Round the diamond into a period
  • Stretch gaps or scale the diamond independently of the type
  • Recolor or facet the spectrum wing
  • Substitute a live web font for production lockup assets
  • Use a circular border spinner, Cursor grey dots, Hangar Drift, or SpectrumLoader assemble as the session-WIP mark

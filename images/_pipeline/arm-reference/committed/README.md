# Curated ARM reference subset

This directory is tracked in git; the rest of `arm-reference/` is not.

Put five to eight representative images from the AI Records Manager set here so a
Cowork session running without the local copy — a remote container, a fresh
clone — still has style reference for the 21 isometric images in the spec.

Pick for coverage of the house style, not for subject matter:

- two or three isometric concept diagrams (the angle, line weight and platform
  thickness to match)
- one that shows how nodes / verified markers are drawn
- one that shows the accent-colour discipline (how sparingly orange and gold are
  used against navy)
- one abstract or texture piece, if the set has one

These are raw downloads with the Gemini sparkle still on them. That is fine here —
this is look-at material, not ship material. Don't patch them and don't rename
them; keep the original ARM filenames so provenance stays traceable.

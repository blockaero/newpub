Security Practices

How We Protect the Network

Access Control

Role-based, least-privilege access across the platform; organization-scoped permissions; joiner/mover/leaver reviews on a weekly operations cadence.

Encryption & Segregation

Data encrypted in transit and at rest, with strict segregation between sandbox, production, and customer private channels.

Blockchain Integrity

Permissioned Hyperledger Fabric network — endorsement policies control which verified organizations can write which records, and every write is signed and timestamped.

Testing & Resilience

Independent penetration testing and business-continuity / disaster-recovery exercises on an annual cadence, with continuous vulnerability monitoring.

Supplier Security

Tiered vendor assessments — any provider touching customer data signs a data processing agreement and is monitored on an ongoing basis.

Incident Response

Documented response process with 72-hour root-cause targets and corrective-action tracking through closure. Report concerns: support@block.aero.
